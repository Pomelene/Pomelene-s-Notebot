# Pomelene Notebot 1.3.0 — diverse 多版本适配

支持 Minecraft **26.1、26.1.1、26.1.2、26.2、26.3** 的 Fabric 客户端。歌曲解析、播放、检测和调音共用源码，每个游戏版本生成一个对应 JAR。

安装时按游戏版本选择一个 JAR，并安装对应版本的 Fabric API。Loader / API 的兼容环境及验证范围见 [COMPATIBILITY.md](COMPATIBILITY.md)。

## 界面与操作

按 N 打开模组，主界面分为两列，左侧约 2/3、右侧约 1/3。整体最大宽度由 900 缩小为 720，随窗口大小调整：

- **左侧歌曲目录**：浏览文件夹、搜索、新建目录、刷新和加载歌曲。文件夹优先显示；悬停歌曲可查看歌名和相对路径。
- **右侧播放页**：进度拖动、开始/暂停/继续、停止、检测、两种调音、检测详情、播放速度和曲目兼容选项。
- **右侧设置页**：检测半径、调音发包速率、八度折回、循环和直接发包。

左侧目录始终显示，右侧在播放和设置之间切换；选歌后切到播放页。进度条的当前时间和总时长保留一位小数（0.1 秒），不改变播放和拖动精度。

F8 开始/暂停/继续，F9 停止并重置。按键可以在游戏控制设置中修改。

## 歌曲目录与搜索

歌曲放在当前游戏实例的 **notebot/songs**，支持自己创建子文件夹。

顶部显示当前相对路径，提供上级、根目录、新建文件夹、打开文件夹和刷新。普通浏览只读取当前目录。输入搜索词后搜索当前目录及子目录，停止输入约 0.3 秒后更新结果。

支持文件名和曲谱内歌名，以及中文拼音、拼音首字母、日文罗马音。忽略大小写、空格和常见标点。例如月亮代表我的心可输入 yueliangdaibiao 或 yldbwdx，千本桜可输入 senbonzakura。特殊专名和多音字的字典读音不一定准确，可在文件名中补充读音。

仅在需要读音搜索时加载词典。目录扫描在后台运行，旧搜索会取消；扫描错误显示在界面中。不会联网查询读音。拖入 NBS 会导入当前目录，不覆盖同名文件。

## 调音与检测

检测半径 **1–64 格**，默认 **6 格**，可拖动或输入。距离按眼睛到方块边界计算，扫描目标必须已加载，上方为空气；不做视线遮挡检查。大范围交互仍需服务器允许。

- **自动调音**：只补齐当前歌曲需要的乐器和音高。
- **全音色检测并调音**：无需加载歌曲，每种音色至少有 25 个可用盒时，为其中 25 个补齐完整 0–24 音阶。保留正确音高，跳过数量不足的音色，多余的盒不修改。

支持 20 种世界音色，包括铜块四种氧化状态对应的铜号。调音速度 **1–80 包/秒**，默认 **20**。每批等待服务端确认，实际速度受网络与服务器影响。调音时松开潜行键。

## 智能音色分配

不兼容歌曲的兼容窗口中，偏好按钮位于智能分配旁边。点击后会显示六种可直接选择的模式：均衡、钢琴、管弦、原声、电子、明亮。悬停模式可查看说明。

选择偏好后重新分析，保留手动指定的音色，偏好自动保存。微分音处理和八度折回仍由用户确认。分配会参考分层结构、相对音域、琶音与节奏等证据，减少重复低音和伴奏被混淆的问题。

一个自定义音色仍使用整曲固定映射；承担多个声部时标为混合并降低置信度。规则判断不保证对所有曲目都准确，建议试听并手动调整。

## 播放与兼容性

保留 1.1.1 的 NBS 读取和兼容转换：自定义音色需要指定对应的原版音色，微分音可以确认近似处理或跳过，超出 NBS 33–57 音域时可折回八度。折回和近似可能改变原曲。

默认使用曲谱原速，可以在播放速度设置中调整；进度滑块可定位歌曲。方块被改调、盖住、破坏或超距时会暂停。

直接发包默认关闭。关闭时需要空手，其他界面和窗口失焦会中断；开启后忽略这些客户端限制。服务端仍按真实手持物品处理，工具可能破坏音符盒。两种模式都要求存活且处于生存模式。

支持 Classic NBS 和 OpenNBS 1–6。NBS 6 内置铜号编号 16–19 可直接匹配原版音色；仍按文件头的内置音色数量区分自定义音色，旧曲谱的自定义编号不会被误当成铜号。自定义采样仍需在兼容选项中选择映射。

## 安装与维护

需要 Java **25**。26.1 系列以 Loader **0.18.4** 为兼容基线，26.2 / 26.3 以 **0.19.3** 为兼容基线；对应 Fabric API 版本见兼容表。
退出游戏后更新 mods 内的 Notebot JAR，只保留一个启用版本。歌曲和 config/pomelene-notebot.properties 保留。

构建使用 JDK 25、Gradle 9.5。主 JAR 内包含 Kuromoji/IPADIC，本机 Minecraft 提供 ICU4J；依赖遵守各自许可，项目采用 MIT 许可。

## 增强检测与世界定位（1.2.5）

在播放页点击 **检测详情**：

- 概览列出全部 20 种音色，即使没有检测到盒子也显示。每行给出可用盒子数量、不同音高覆盖（0–24）、当前歌曲匹配数量和排除数量。
- 悬停音色行查看歌曲缺失音高、完整 25 音阶缺失和盒子数量缺口；重复音高算多个盒子，但只算一种音高。
- 点击音色行查看该音色每个盒子的坐标、音高和状态；也可以查看全部位置。筛选可用、上方阻挡、超出半径或不支持音色，悬停阻挡行查看上方方块。
- 开启高亮：绿色为已匹配歌曲，黄色为其他可用盒子，红色为上方阻挡，橙色为超距，紫色为不支持音色。点击位置行返回世界，仅定位该盒子。
- 高亮可穿过遮挡，仅在本地显示，不修改方块、不发包。按当前音色和筛选最多显示 256 个，关闭高亮或切换世界后取消。

未加载区块会提示检测结果可能不完整。超距列表只记录扫描边界区域中实际找到的盒子，不扫描整个世界。多个排除原因同时存在时，优先显示超距，然后上方阻挡，最后不支持音色，保持原有播放判断。

检测规则仍是距离、上方为空气及受支持音色，不做视线遮挡检查。检测不会自动调音；两种调音仍需主动点击。

## 构建与测试

使用 JDK 25 和自带的 Gradle Wrapper，默认目标为 26.3：

```powershell
./gradlew.bat build '-PmcVersion=26.1.2'
./gradlew.bat runClientGameTest '-PmcVersion=26.1.2' '-PfabricProfile=latest' '-PnotebotTestSuite=matrix'
python tools/build_matrix.py --verify
python tools/package_matrix.py
```

单版本输出在 `build/<游戏版本>/<baseline 或 latest>/libs/`。全矩阵打包输出在 `build/releases/`。安装不带 `-sources` 的 JAR，且只安装匹配当前 Minecraft 版本的一个文件。

`baseline` 使用兼容表中的较早 Loader / API；`latest` 使用表中固定的新版本。生产代码始终按较早 API 编译，测试运行时切换依赖，以验证同一个 JAR 对两组环境的兼容性。

客户端测试使用临时世界，检查播放、自动调音、64 格半径、全 20 音色、排除原因、筛选、定位和高亮。`-PnotebotTestSuite=ui` 可单独检查目录、搜索和设置界面。

歌曲、游戏目录、构建缓存、运行日志和本机截图不纳入仓库。
